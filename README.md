   **Face Recognition with PCA and LDA**
This project implements face recognition using Principal Component Analysis (PCA) and Linear Discriminant Analysis (LDA) on the ORL face dataset. The system performs dimensionality reduction and classification using K-Nearest Neighbors (KNN). It also includes experiments for face vs non-face classification and performance comparisons between PCA and LDA.
This project was completed as part of the Pattern Recognition course at the Faculty of Engineering, Alexandria University.

**🔧 Project Structure**
- FR_Notebook.ipynb : Main Jupyter notebook with all code and results
- Report.pdf/.docx : Full project report with explanations, screenshots, and analysis
- dataset : ORL face dataset https://www.kaggle.com/datasets/kasikrit/att-database-of-faces
